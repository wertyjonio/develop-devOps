# Flask Catnip Web Application in Docker

Учебный пет-проект по контейнеризации простого веб-приложения на Python/Flask, раздающего случайные гифки с кошками. Проект создан в рамках изучения DevOps-стека для демонстрации навыков работы с Docker, сборки кастомных образов и облачного деплоя.

## 🛠️ Стек технологий
* **Language:** Python 3.10
* **Framework:** Flask
* **Containerization:** Docker
* **Base Image:** Alpine Linux / Python-slim
* **Cloud Platform:** Render (Serverless Web Services)

## 🏗️ Особенности реализации и Дебаг
В процессе работы над проектом были успешно решены следующие инфраструктурные задачи:
* **Исправление архитектуры путей:** Устранена ошибка `jinja2.exceptions.TemplateNotFound: index.html` путем создания правильной структуры шаблонов внутри контейнера (`templates/`) и фиксации рабочей директории через `WORKDIR`.
* **Оптимизация сборки:** Настроена сборка через `--network=host` для обхода ограничений DNS-резолвинга в среде WSL.
* **Облачный деплой:** Проведен успешный бесшовный деплой готового образа из Docker Hub в облачную среду Render с пробросом внутренних портов (веб-трафик перенаправлен на внутренний порт приложения `5000`).

## 🚀 Как запустить локально

1. Сборка кастомного Docker-образа:
```bash
docker build -t wertyjonio/catnip:latest .
```

2. Запуск контейнера в фоновом режиме с пробросом портов:
```bash
docker run -d -p 8080:5000 --name cat-app wertyjonio/catnip:latest
```
После этого приложение будет доступно в браузере по адресу `http://localhost:8080`.

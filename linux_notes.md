# Обучение DevOps — Ступень 2: Linux Basics

## 1. Продвинутая навигация и аудит файлов
* `pwd` (Print Working Directory) — показать текущий абсолютный путь.
* `file <имя>` — определить реальный тип файла (текст, бинарник, архив).
* `stat <имя>` — вывести полную информацию о файле (размер, права, даты изменений).
* `tree` — показать структуру папок и вложений в виде дерева.
* `find . -name "*.md"` — мощный поиск файлов по маске во всех подпапках.

## 2. Потоки и перенаправления
* `>` — записать стандартный вывод (`stdout`) в файл с полной перезаписью.
* `>>` — дописать текст в самый конец файла (используется для ведения логов).
* `|` (Пайп / Конвейер) — передать вывод одной команды на вход другой.
* `2>&1` — склеить поток ошибок (`stderr`) с полезным выводом (`stdout`) для честного сбора логов.

## 3. Переменные окружения
* `env` — вывести список всех активных глобальных настроек системы.
* `export VAR="value"` — сделать переменную видимой для всех запущенных программ.
* `$PATH` — список системных папок, где Linux ищет программы при вводе команд.
* `.bashrc` — скрытый файл настроек пользователя, который запускается при каждом открытии терминала.

## 4. Права доступа (`chmod`)
* У каждого файла есть 3 группы прав: Владелец, Группа, Остальные.
* Буквы: `r` (чтение), `w` (запись), `x` (запуск скрипта/программы).
* `chmod +x script.sh` — дать файлу права на запуск (файл подсветится зеленым).

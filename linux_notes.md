## 1. Продвинутая навигация и аудит файлов

*   `pwd` (Print Working Directory) — показать текущий абсолютный путь от корня системы (`/`).
*   `file <имя>` — определить реальный тип файла по его сигнатуре (магическим байтам), а не по расширению (покажет: текст, бинарник, скрипт, архив).
*   `stat <имя>` — вывести полную метаинформацию о файле: размер, владельца, права доступа в числовом виде и три главные даты (время создания, изменения контента, последнего доступа).
*   `tree` — показать структуру текущей папки и всех вложений в виде наглядного графического дерева.
*   `find <где> -name "<маска>"` — мощный поиск файлов на диске. 
    *   *Пример:* `find . -name "*.md"` — искать все Markdown-файлы в текущей папке и ниже.
*   `locate <имя>` — мгновенный поиск файлов по всей системе через готовую базу данных. Работает быстрее `find`, но требует обновления базы командой `updatedb` после создания новых файлов.
*   `ln <файл> <имя_ссылки>` — создание **жесткой ссылки** (hard link). Ведет на те же данные на диске. Если удалить оригинал, жесткая ссылка продолжит работать.
*   `ln -s <файл> <имя_ссылки>` — создание **символической ссылки** (soft/symbolic link). Аналог ярлыка в Windows. Если удалить оригинал, ссылка станет «битой» (нечитаемой).

## 2. Потоки данных и перенаправления

В Linux у любого процесса есть три стандартных потока ввода/вывода:
*   `0` (`stdin`) — стандартный ввод (клавиатура).
*   `1` (`stdout`) — стандартный полезный вывод (экран).
*   `2` (`stderr`) — стандартный вывод ошибок (экран).

### Операторы перенаправления:
*   `>` — направить `stdout` в файл с **полной перезаписью** старого содержимого.
*   `>>` — направить `stdout` в файл, **дописывая** строки в самый конец (сохраняет старые данные).
*   `2>` — перенаправить исключительно поток ошибок `stderr` в файл, скрыв их из терминала.
    *   *Пример:* `cat non_existent.txt 2> errors.log`
*   `2>&1` — склеить поток ошибок (`2`) с полезным выводом (`1`). 
*   `|` (Пайп / Конвейер) — передает `stdout` первой команды на `stdin` второй команды, позволяя строить цепочки обработки.

## 3. Переменные окружения

*   `env` — вывести список всех активных глобальных (системных) переменных текущей сессии.
*   `export VAR="value"` — превратить локальную переменную терминала в глобальную переменную окружения, доступную для всех дочерних процессов и скриптов.
    *   *⚠️ Подводный камень:* Вокруг знака `=` **нельзя ставить пробелы** (`VAR = "val"` вызовет ошибку). Значок `$` ставится только при чтении переменной (`echo $VAR`), при создании он не нужен.
*   `$PATH` — критически важная переменная. Содержит список папок, разделенных двоеточием, в которых Linux ищет исполняемые файлы команд.
    *   *Временное добавление пути (до закрытия терминала):* `export PATH="$PATH:/home/user/my_folder"` (обязательно сохранять старый `$PATH` через двоеточие!).
    *   *Добавление текущей папки (`.`):* `export PATH="$PATH:."` — позволяет запускать скрипты из текущей папки просто по имени: `script.sh`.
*   `.bashrc` — скрытый конфигурационный файл в домашней директории пользователя. Выполняется **каждый раз при открытии нового окна терминала**. Именно сюда нужно прописывать кастомные `export PATH` и алиасы для постоянной работы.
*   `.bash_profile` / `.profile` — выполняются **один раз** при первом входе (логине) пользователя в систему.

## 4. Комплексная работа с текстом (Текстовые пайплайны)

*   `grep [опции] "шаблон" <файл>` — поиск строк по тексту или регулярному выражению.
    *   `-i` — игнорировать регистр букв.
    *   `-v` — инвертировать поиск (показать строки, где текста **нет**).
    *   `-n` — вывести номера строк.
*   `sort` — сортировка строк по алфавиту. Флаг `-n` включает правильную сортировку чисел, флаг `-r` разворачивает сортировку в обратном порядке.
*   `uniq` — удаление **повторяющихся подряд** строк. 
    *   *⚠️ Правило:* Перед `uniq` всегда должна идти команда `sort`.
    *   `-c` — посчитать количество уникальных повторений каждой строки.
*   `cut` — вертикальное вырезание колонок текста. Флаг `-d` задает символ-разделитель, флаг `-f` указывает номер нужного столбца.
*   `wc` (Word Count) — подсчет метрик текста. Флаг `-l` считает точное количество строк.
*   `xargs` — берет строки из пайпа и передает их в качестве аргументов команде, которая не умеет читать `stdin` напрямую. Флаг `-r` отменяет запуск следующей команды, если на вход ничего не пришло.
    *   *Пример:* `find . -name "*.log" | xargs -r rm`
*   `sed` — потоковый текстовый редактор. Используется для автозамены «на лету».
    *   *Пример:* `sed -i 's/old/new/g' file.txt` (флаг `-i` сохраняет изменения в файл).
*   `awk` — мощный процессор структурированного текста. Автоматически разбивает строки на столбцы `$1`, `$2`, `$3` по пробелам.
    *   *Пример анализа реального лога (Топ-3 IP со статусом 200):*
        `grep "200" access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 3`

## 5. Основы автоматизации: Bash-скриптинг

Каждый скрипт — это текстовый файл с расширением `.sh`, написанный строго построчно.

### Базовый скелет скрипта:
```bash
#!/bin/bash    # Шебанг (Shebang) — указывает системе интерпретатор для выполнения

# 1. Объявление переменных (БЕЗ пробелов вокруг '=')
BACKUP_DIR="backup_folder"

# 2. Выполнение системных команд
mkdir -p \$BACKUP_DIR

# 3. Конструкция условий if/else
# ⚠️ Важно: Внутри квадратных скобок пробелы ОБЯЗАТЕЛЬНЫ с обеих сторон!
# Флаг -e проверяет существование файла. Условие закрывается перевернутым словом 'fi'.
if [ -e "access.log" ]; then
    cp access.log \$BACKUP_DIR
    echo "[OK] Файл скопирован"
else
    echo "[ERROR] Файл не найден"
fi

# 4. Конструкция циклов for
# Перебирает список элементов. Тело цикла находится между 'do' и 'done'.
for file in nginx.conf app.conf db.conf
do
    echo "Проверяю конфигурацию: \$file"
done
```

### Важные операторы сравнения чисел в `if`:
*   `-eq` — равно (equal)
*   `-ne` — не равно (not equal)
*   `-gt` — больше (greater than)
*   `-lt` — меньше (less than)
*   `-ge` — больше или равно (greater or equal)

## 6. Права доступа (`chmod`)

*   У каждого объекта в Linux есть 3 категории доступа: **U**ser (Владелец), **G**roup (Группа владельца), **O**thers (Все остальные).
*   Базовые типы прав:
    *   `r` (read) — чтение содержимого.
    *   `w` (write) — изменение содержимого (удаление/запись).
    *   `x` (execute) — право на запуск файла как программы или скрипта.
*   `chmod +x script.sh` — добавить флаг исполняемости для владельца, после чего Bash позволит запускать скрипт напрямую через `./script.sh` (в терминале имя файла подсветится зеленым цветом).
